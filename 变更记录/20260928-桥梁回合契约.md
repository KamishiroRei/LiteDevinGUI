## 新增能力

### `POST /api/bridge/turn/start`
入参 `{sessionId?, cwd, text, images?, model?, modeId?, clientTurnId?, clientMessageId?}`。
- 无 sessionId → `session/new`；有 → `session/load`（本进程已驻留则跳过 load）。
- 会话 `configOptions` 含 `model` 选项时校验请求值在 options 内，否则 422；`observedModel` 取 `configOptions.model.currentValue`，证据级别字段 `modelEvidence: 'session-config-option' | 'set-request'` —— 只证明"选中值"，不伪造 CLI `--export` 的 `model_name`。
- 默认 `model='swe-2-high'`、`modeId='bypass'`；依次 `session/set_config_option` + `session/set_mode`，失败如实 HTTP 错误（回合未建立）。
- 会话加入 `autoApproveSessions`；建立 turn 记录（`bt-*` turnId）→ 立即 dispatch —— **返回时 busy 引用计数已建立**（响应含 `busy` 值），供桥梁在全局容量锁内准入。
- `clientTurnId` 幂等：重复 start 返回 `{...turnView, deduped:true}`。

### `GET /api/bridge/turn/status?turnId=&waitMs=`
- 状态 `running | deferred | done | error | cancelled`；字段 `attempts/queueId/retryAt/lastError/stopReason/usage/error/code/createdAt/finishedAt`。
- `waitMs` ≤30000 长等——**每次状态迁移唤醒**（客户端循环到终态为止）。
- turn 仅存进程内存：重启后未知 turnId → **404**，桥梁应标不确定而非静默重发。

### `POST /api/bridge/turn/cancel`
`{turnId}` → 摘除其排队重试项 + `session/cancel` 通知 → `cancelled`；终态后调用无副作用。`/api/cancel`、`/api/sessions/delete`、`/api/queue/drop` 同步把相应 turn 置 `cancelled`。

### 权限自动批准（桥接 bypass 等价）
`autoApproveSessions` 内会话的 `session/request_permission` 自动应答：优先选 optionId/name/kind 匹配 `allow|always|approve|accept|yes` 的选项，否则第一项；无选项则回 `cancelled` outcome；发 SSE `permission-auto` 事件。GUI 会话维持原人工 `/api/permission` 流程。

### `clientMessageId` 透传
`/api/prompt` 与 turn/start 均接受；透传到 SSE `prompt-dispatch` / `prompt-deferred` / `prompt-done`（成功与错误两种），供前端并发插话错误归属。

## 顺路修复的真实缺陷

- `CONCURRENCY_RE` 缺 "prompts too quickly" 形态：真实 ACP 并发拒绝若以 "sending prompts too quickly / too quickly" 文案返回，会被误判为终态 error 而非延期。默认正则补 `too.{0,5}quick`（env `DEVIN_LITE_CONCURRENCY_RE` 仍可覆盖）。
- turn 状态机终态守卫：cancelled/done/error 后晚到的 prompt 解析不再改状态。

## 联调返修 v2（报告 r_629b983495554228 反馈，哈希 e4c4b0ab → 527b3b40）

1. **observedModel 取设置后证据**：原来回读 `session/new|load` 的旧 `configOptions.model.currentValue`，初始模型非 swe-2-high 时会谎报旧值。改为 `session/set_config_option` 成功后，优先用其响应回显的 `configOptions[].currentValue`（`modelEvidence:'session-config-option'`），无回显则以"已接受的 set 请求值"为证据（`'set-request'`）；仍不伪造生成时 model_name。
2. **status 长等 waiter 泄漏**：`turn.waiters` 的回调现在自移除——超时和状态唤醒两条路径都从 Set 删除；`turnView` 新增 `pendingWaiters` 便于观察与断言。
3. **cancel 按在途状态分级**：`deferred` 态只撤自己的排队项、不发 `session/cancel`；`running` 态仅在独占在途（本 turn 是会话唯一 in-flight prompt）时发全会话取消；同会话还有其他在途 prompt（如 GUI 插话）时返回 **409** `{error, conflict:true, sessionBusy, ...turnView}` 且 turn 保持 `running`。`/api/cancel` 会话级入口语义不变（显式用户操作）。
4. `httpError` 支持 `extra` 字段透传到错误响应 JSON（409 冲突上下文）。
